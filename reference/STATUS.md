## Licence obligations

Reading any of these is unrestricted. **Depending** on the ones below is a decision with consequences — check before importing, not after.

- **Source-available, not open source:** vectorbt (Apache-2.0+CommonsClause). The Commons Clause forbids selling the software or any product or service whose value derives substantially from it, including hosting and support. Personal and research use only.
- **Strong copyleft (network clause):** hyperagent (AGPL-3.0), backtesting.py (AGPL-3.0). Modify it and let anyone reach it over a network, and you must publish your modified source. Keep it in a separate process behind a documented interface, or avoid it.
- **Weak copyleft:** nautilus_trader (LGPL-3.0). Linking is generally fine; modifications to the library itself must be published. Safer than AGPL, still not MIT.

## Why each project is here

- **buzz** (`block/buzz`) — Block's open-source workspace where AI agents are first-class members with their own Nostr identity. This is the chat interface the bot is handed off through. Launched 2026-07-21 and still early (0.4.x, no mobile client), so pin deliberately and read release notes before bumping.
- **hermes-agent** (`NousResearch/hermes-agent`) — Nous Research's agent runtime — memory, skills, approval gates, cron delivery, MCP client support, and a documented Buzz integration. Provides the persistence and approval layer that a bare Claude Code session lacks.
- **goose** (`block/goose`) — Block's own agent framework, natively supported by Buzz alongside Claude Code and Codex. Worth reading for how it models extensions and tool permissioning even if we stay on Claude Code.
- **atomic-agents** (`BrainBlend-AI/atomic-agents`) — Lightweight agent framework built on Instructor and Pydantic, favouring explicit control flow over autonomy. Closest in philosophy to this repo's "model proposes, code disposes" split — useful reference for structuring the decision step without handing over control.
- **eliza** (`elizaOS/eliza`) — The most established crypto/on-chain agent framework, with a large plugin ecosystem for market data, wallets and social feeds. Reference for the crypto sleeve and for sentiment ingestion patterns.
- **letta** (`letta-ai/letta`) — Agents with long-term persistent memory (formerly MemGPT). Relevant if the bot should genuinely learn across sessions rather than re-reading its audit log each time.
- **hyperagent** (`hyperbrowserai/HyperAgent`) — Playwright-based browser automation with MCP support. The legitimate route to sources that have no usable API — Truth Social in particular, and X without paying for the $200/mo tier. TWO CAVEATS, both load-bearing. (1) LICENCE: this is AGPL-3.0, the only copyleft project in this registry. Its network-use clause means that if you modify it and let anyone reach it over a network, you must publish your modified source. Reading it for reference is fine; importing it into this bot is a licensing decision, not just a technical one. Keep it in a separate process talking over a documented interface if you use it at all. (2) TERMS OF SERVICE: automated scraping breaches many sites' terms. Check the target's terms before pointing this anywhere, and prefer a paid API where one exists.
- **alpaca-mcp-server** (`alpacahq/alpaca-mcp-server`) — Alpaca's official MCP server — not just reference, an actual dependency. Exposes 80+ trading and market-data tools and defaults to paper trading. Restrict it with ALPACA_TOOLSETS so our own MCP server stays the only order-placing path.
- **backtesting.py** (`kernc/backtesting.py`) — The simplest credible backtester — small API, clean docs, readable source. Start here: a first harness that works beats a sophisticated one that never gets finished. LICENCE WARNING: AGPL-3.0. Fine to read and to run privately, but importing it into anything network-exposed carries the copyleft obligation. If the backtester ends up embedded in this bot, prefer an MIT/Apache alternative or keep it in a separate offline process.
- **vectorbt** (`polakowo/vectorbt`) — Vectorised backtesting built for parameter sweeps — the fastest way to ask "does this signal have any edge at all?" across a large grid. Weak on execution realism, so treat its results as triage rather than proof. LICENCE WARNING: Apache-2.0 **with the Commons Clause**, which makes this source-available rather than open source despite how it is usually described. The clause forbids selling the software or any product or service whose value derives substantially from it — including hosting and support. Personal and research use is fine; anything commercial is not, and no amount of restructuring changes that. If this bot ever becomes a product, replace vectorbt rather than argue about it.
- **nautilus_trader** (`nautechsystems/nautilus_trader`) — Production-grade event-driven engine with realistic fills, latency modelling and backtest/live parity — the same strategy code runs in both. Steep learning curve; the right graduation target once a strategy is worth testing properly. Note it defaults to the `develop` branch, not `main`.
- **TradingAgents** (`TauricResearch/TradingAgents`) — The most established multi-agent LLM trading framework, modelled on the desk structure of a real trading firm (analysts, researchers, trader, risk manager) with Claude among its supported providers. The closest thing to prior art for what this repo is doing, and the best single source for how a multi-agent version would be shaped.
- **ai-hedge-fund** (`virattt/ai-hedge-fund`) — Runs a panel of investor personas that argue a position before it is taken. A genuinely different architecture from a single proposing model, and the adversarial framing is a plausible answer to the Alpha Arena finding that lone models are confidently wrong at a 25-30% win rate.
- **FinRL** (`AI4Finance-Foundation/FinRL`) — Reinforcement learning for trading, with a documented path from research notebooks through to live Alpaca execution — the same broker this bot uses, so its execution layer is directly readable. Also a useful counterweight: RL optimises a stated objective, which forces you to say what "good" means instead of leaving it to a model's judgement.
