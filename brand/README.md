# Mudhorn Capital web app

The public site. Six pages, no build step, no framework, and no network request
at runtime. Open any `.html` file in a browser and it works, including from
`file://`.

## Where it is live

**https://mudhorn-capital.vercel.app**

Vercel, imported from this repo with **Root Directory** set to `brand`,
framework "Other", no build command. Every push to the tracked branch
redeploys. Links between pages carry their `.html` extension, so the site needs
no rewrite rules and no `vercel.json`.

## The one hard constraint

**Every figure on this site is synthetic.**

`assets/demo-data.js` is a committed fixture generated by
`scripts/generate_demo_data.py`. There is no fetch anywhere in the app and there
is no API to fetch from. A persistent banner at the top of every page says so,
and the banner is plain HTML in each file rather than something a script writes,
so the label cannot fail to appear.

This is not a stylistic preference. The real dashboard in `src/bot/web/` renders
live account equity, open positions and realised P&L, and it has no login
*because* it binds to `127.0.0.1`. Publishing it would put a live view of a
brokerage account on the open internet. CLAUDE.md covers this under "One
directory is published. The rest must never be", and the sign-in page here is
explicitly labelled as a prototype shell rather than authentication.

If the site should ever show real numbers, that is a separate and much larger
project: real authentication, an API out of the droplet, TLS, and a threat
model. It is not a matter of pointing this app at a different data source.

`config/rules.yaml` is the one exception, reproduced verbatim on the Rules page.
It holds limits rather than secrets and is already public in this repository.

## Pages

| File | What it is |
| --- | --- |
| `index.html` | Launch pad. No form, no session, no gate: one link into the demonstration, which fx.js turns into a jump to lightspeed. |
| `overview.html` | Equity curve, open positions, P&L, risk against the caps, stand-down state. |
| `trades.html` | Filterable journal. Every trade carries the reasoning recorded against it. |
| `analytics.html` | Win rate, profit factor, expectancy, R distribution, drawdown, excursion capture. |
| `rules.html` | `config/rules.yaml`, read-only. |
| `about.html` | The identity reference, plus what this site is. |

`assets/app.css` is the design system, `assets/app.js` holds formatting, metrics
and the SVG charts, `assets/fx.js` is the projection layer, `assets/demo-data.js`
is the fixture, `assets/mark.svg` is the favicon.

## The projection layer

`assets/fx.js` adds a perspective starfield, a hyperspace jump between pages, HUD
bracket corners and panels that materialise on arrival. It is the same engine as
the live command centre in `src/bot/web/`, so the two surfaces move the same way.

It is decoration and it is built so it cannot become anything else.

- **Nothing starts hidden unless the script said so.** The entry animations need
  both `html.fx-ready` and a per-element `fx-panel` class, added together in one
  synchronous block, with a timer that force-finishes every panel whatever
  happened in between. Script blocked, script threw, JavaScript off: the plain
  site renders with every figure visible. Hiding in CSS and revealing in JS fails
  to a blank page, which is why it is done the other way round.
- **The demo banner is not in the panel list.** It is plain HTML in all six files
  so the label saying these figures are invented cannot depend on a script having
  run, and an entry animation would undo exactly that.
- **The landing page link is an ordinary link first.** `fx.js` turns it into a
  jump to lightspeed and `overview.html` completes it on arrival, but with the
  script absent it still just goes there. An entrance that can fail closed is not
  an entrance.
- **The boot readout names parts of the interface, never a figure.** Its last
  line reads `Data source: FIXTURE`, which is the same thing the banner says.

## Regenerating the fixture

```sh
python scripts/generate_demo_data.py
```

Fixed seed, so a regeneration produces the same dataset and a reviewable diff.
The script asserts its own output before writing: no trade may exceed the 1%
per-trade risk cap, open risk may not exceed 2%, every trade must carry a stop,
and the limits echoed into the JSON must still match `config/rules.yaml`. A demo
that showed a 1.4% single-trade risk against a 1% cap would teach the reader the
wrong thing about what the gate does.

The seed was picked to produce an unremarkable year: 48 trades, a profit factor
of 1.07, about half a per cent on the year and two stand-down trips. A seed that
printed a handsome equity curve would be the wrong thing to publish.

## Design

Carried over from the identity reference, which is now `about.html`.

- **Ink** `#0B0E12`, **Graphite** `#161B22`, **Slate** `#29313C`,
  **Pewter** `#7D8896`, **Bone** `#E9ECEF`, **Patina** `#4E8C7D`.
- Two colours are added for the interface and used only on figures and the small
  state chips: **Gain** `#5FA795` and **Loss** `#C0707B`. A book of forty trades
  has to be scannable for wins against losses without reading every number, and
  the identity palette has one accent by design. Chrome, links and focus rings
  still belong to patina, so the accent keeps meaning something. Loss is a cold
  rose rather than a warm red, because a warm red on this ground reads as brick.
- Serif for display, sans for body, mono for every figure, all set with
  `font-variant-numeric: tabular-nums` so a changing digit never shifts a row.
- 2px radius. Rounded corners read consumer app.

## Accessibility

`prefers-reduced-motion` is honoured, and switched **off** rather than slowed
down: animations and transitions are disabled, the identity reveal shows its
final state immediately, the replay control is hidden, and `fx.js` returns before
it starts the canvas, so the starfield and the hyperspace jump are never built at
all. A full-screen radial starfield accelerating to lightspeed is close to a
worked example of a vestibular trigger, and a gentler one is not what was asked
for. Focus is visible throughout. Charts carry `role="img"` and a
spoken summary, and every chart is also described in words beneath it.

Tables become stacked records below 760px rather than scrolling sideways,
because a forty-row journal read sideways on a phone is not readable. Verified
at 390px and 1280px.

## Compliance line

Never "our clients", never "we manage", and no performance claim. This is a
private vehicle trading its own paper money, and phrasing that implies otherwise
has a regulatory meaning in the US. British English throughout, and no em
dashes.
