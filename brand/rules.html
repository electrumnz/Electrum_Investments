Rules

These are enforced in deterministic Python before any order reaches a broker, not by asking a model nicely. A rejection is final, and the way to change behaviour is to change this file in a commit, with a reason, never to argue with the agent.

The four that matter

Read-only

Nothing on this page can be edited, here or anywhere else on this site. That is deliberate rather than unfinished. Limits that could be widened from a browser would be limits that get widened at exactly the moment they are doing their job, which is during a losing run.

In the repository this file is owned by root and the service account that runs the bot cannot write to it, so the process cannot edit its own limits either.
